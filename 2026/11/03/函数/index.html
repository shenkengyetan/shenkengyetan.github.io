字符串函数

函数 功能 示例 结果
CONCAT(S1,S2,...Sn) 字符串拼接 CONCAT('Hello',' ','World') Hello World
LOWER(str) 全部转小写 LOWER('Hello') hello
UPPER(str) 全部转大写 UPPER('Hello') HELLO
LPAD(str,n,pad) 左填充到长度 n LPAD('01',5,'0') 00001
RPAD(str,n,pad) 右填充到长度 n RPAD('01',5,'0') 01000
TRIM(str) 去掉首尾空格 TRIM(' abc ') abc
SUBSTRING(str,start,len) 从 start 起取 len 个字符 SUBSTRING('abcdef',2,3) bcd

TRIM直去除头部和尾部的空格

SUBSTRING的第一个字母的索引为1

update 表名 set 字段名=lpad(字段名,5,-);[这是要更新表]

数值函数

函数 功能 示例 结果
CEIL(x) 向上取整，返回大于等于 x 的最小整数 CEIL(3.2) 4
FLOOR(x) 向下取整，返回小于等于 x 的最大整数 FLOOR(3.8) 3
MOD(x,y) 返回 x 除以 y 的余数/模 MOD(10,3) 1
RAND() 返回 0~1 之间的随机数（MySQL 中为 [0,1)） RAND() 如 0.732...
ROUND(x,y) 对 x 四舍五入，保留 y 位小数 ROUND(3.14159,2) 3.14

通过数据库生成一个6位随机数

sellect lpad(round(rand()*1000000,0),6,’0’);

时间函数

函数 功能 示例 结果
CURDATE() 返回当前日期 CURDATE() 2026-10-28
CURTIME() 返回当前时间 CURTIME() 14:30:25
NOW() 返回当前日期和时间 NOW() 2026-10-28 14:30:25
YEAR(date) 获取指定日期的年份 YEAR('2026-10-28') 2026
MONTH(date) 获取指定日期的月份 MONTH('2026-10-28') 10
DAY(date) 获取指定日期的日 DAY('2026-10-28') 28
DATE_ADD(date, INTERVAL expr type) 返回日期加上时间间隔后的值 DATE_ADD('2026-10-28', INTERVAL 7 DAY) 2026-11-04
DATEDIFF(date1,date2) 返回 date1 与 date2 之间的天数差（date1 − date2） DATEDIFF('2026-11-04','2026-10-28'） 7

查询入职到现在过了多长时间

sellect name,datediff(‘curdate()’,’day’) as ‘days’ from emp order by desc;

IFNULL(value1, value2) value1 不为 NULL 返回 value1，否则返回 value2 IFNULL(NULL,'默认') 默认
