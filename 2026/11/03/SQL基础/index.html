SQL分类

DDL数据定义语言，用来定义数据库对象(数据库，表，字段)
DML数据操作语言，用来对数据库表中的数据进行增删改
DQL数据查询语言，用来查询数据库中表的记录
DCL数据控制语言，用来创建数据库用户、控制数据库的访问权限

查询

SHOW DATABASE;查询所有数据库

SELECT DATABASE();查询当前数据库

SHOW TABLES;查询当前数据库所有表

DESC 表名;查询表结构

SHOW CREATE TABLE 表名;查询指定表的建表语句

添加字段

ALTER TABLE 表名 CHANGE 旧字段名 新字段名 类型(长度) [][约束];

修改表名

案例

设计一张员工信息表，要求如下：

  1. 编号（纯数字）
  2. 员工工号(字符串类型，长度不超过10位)
  3. 员工姓名（字符串类型，长度不超过10位）
  4. 性别(男/女，存储一个汉字)
  5. 年龄（正常人年龄，不可能存储负数）
  6. 身份证号(二代身份证号均为18位，身份证中有X这样的字符）
  7. 入职时间(取值年月日即可)

create table emp(

ID int,

workno varchar(10) comment ‘编号’,

name varchar(10) comment ‘姓名’,

gender char(1) comment ‘性别’,

age tinyint unsigned comment ‘年龄’,

idcard char(18) comment ‘身份证号’,

entrydate date comment ‘入职时间’

)comment ‘员工表’;

测试的时候有好多错误

包括但是不限于

  1. verchar、werchar 应改为 VARCHAR
  2. tinint 应改为 TINYINT
  3. age unsigned tinint 应改为 age TINYINT UNSIGNED
  4. gender char(1) comment '性别'， 后面用了中文逗号 ，，应改成英文逗号 ,
  5. UNSIGNED 应放在数据类型后面，写作 TINYINT UNSIGNED

修改数据

UPDATA 表名 SET 字段名1=值1，SET 字段名2=值2 [WHERE 条件]；

删除数据

DELETE FROM 表名 [WHERE 条件];

DELETE语句不能删除某一个字段的值(可以使用UPDATE)。

权限控制

权限 说明
ALL, ALL PRIVILEGES 所有权限
SELECT 查询数据
INSERT 插入数据
UPDATE 修改数据
DELETE 删除数据
ALTER 修改表
DROP 删除数据库/表/视图
CREATE 创建数据库/表

授予权限 GEANT 权限列表 ON 数据库名.表名 TO ‘用户名‘@’主机名’;

撤销权限 ROVOKE 权限列表 ON 数据库名.表名 FROM ‘用户名‘@’主机名’;
