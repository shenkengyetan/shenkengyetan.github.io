约束

约束是对表结构数据的内容进行限制

目的：保障数据的完整性，正确，有效性

分类

约束 关键字 说明
非空约束 NOT NULL 字段值不能为 NULL
唯一约束 UNIQUE 该字段所有值唯一不重复（允许一个 NULL）
主键约束 PRIMARY KEY 一行唯一标识，非空 + 唯一，一张表只能一个主键
默认约束 DEFAULT 插入数据不指定该字段时，自动使用默认值
检查约束 CHECK 限制字段值满足自定义条件（MySQL 8.0.16 + 才真正生效）
外键约束 FOREIGN KEY 关联两张表，维护参照完整性、数据一致性

外键约束

具有外键的表称为子表，外键所关联的称为父表

外键的作用建立两个表之间的连接，确保数据的完整性
